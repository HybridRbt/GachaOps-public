# 公开发布义务与材料

日期：2026-10-28。目标是可公开发布的 external 接入版，不要求完整溯源每个库。此表是实施判断，不代替最终材料及发布批准。

| 范围 | 必要义务 | 材料及边界 |
|---|---|---|
| 应用 AGPLv3 | 许可、对应应用源码及构建输入、使用者权利 | ZIP 含 126 原始输入与明确后补材料，未从 ZIP 再构建，不要求逐字节复现 |
| Qt/PySide LGPLv3 | 使用告知、GPL/LGPL 原文、库源码、可兼容替换及调试修改 | 五份版本源码、保守告知全集、SDK attribution 覆盖、Community 修改 QtCore 加载实验；不宣称 SDK 与 wheel 全部构建选项相同 |
| CPython / permissive 库 | 保留适用版权、许可与告知 | 安装版许可 12 文件及上游全集；可选/仅构建组件的保守收集不是编译 SBOM |
| Mesa/LLVM | MIT/Boost/NCSA 等适用告知 | 原文及版本参考保留；完整补丁历史、工具链考古、逐库重建与字节复现是补充，不默认阻断 |
| Microsoft CRT | 合法开发许可下分发 REDIST 清单允许的未改文件，遵守独立条款 | 个人开发者、Community 安装已确认；五文件为官方有效签名原件；三文件变化有清单；原文随包 |
| 桥接及外部助手 | 自有桥接 AGPL 源码、实际组合义务 | 源码随包；GPLv3 §13 允许相应组合，不凭进程边界免责；不交付外部助手，NTE 网站差异保留参考 |
| 素材 | 自有或获授权 | brand03 自有；七张游戏 PNG 排除候选与应用源码归档 |

无需默认向供应方发信。出现实际适用许可不明、必要告知缺失或未交付的本地修改等具体证据时再解决，不因可选库历史未完全查明而扩大前置条件。

六份源码由 SOURCE_BUNDLE_MANIFEST.json 固定摘要，与二进制一起交付。装配工具只读取指定本地缓存，不下载、不执行源码、不代填批准。DISTRIBUTION_DELIVERY_PROPOSAL.json 固定材料映射，预览通过不自动批准。维护者已于 2026-10-28 批准此前材料及微软运行库替换，随后要求从 9e0d14e 重新制作 ZIP；当前独立 DISTRIBUTION_APPROVAL.json 记录相同许可范围下的新应用源码及运行时摘要，不代表公开发布批准。

真实助手、正常桌面、干净 Windows、未完成的跨平台 CI 验收仍按独立记录判断，不能用材料工作替代。公开仓库路线及正式发布仍由维护者决定。
