## 应用重建

在独立 Windows x64 目录解压应用 ZIP。安装 Python 3.12.14，阅读 requirements-desktop.txt、GachaOps.spec 和 scripts/Build-Desktop.ps1。直接依赖为 PyInstaller 6.22.0、PySide6-Essentials 6.10.2、Shiboken6 6.10.2。

先执行 git init、git add .、git commit，建立自己的干净源码提交，然后执行：

```powershell
./scripts/Build-Desktop.ps1 -Python <Python绝对路径> -DependenciesDirectory <已核对的依赖目录> -OutputDirectory <不存在的新目录> -RequireClean
```

不提供依赖目录时会调用 pip。三个直接依赖版本检查不等于完整锁定，应保留实际下载清单。无需恢复作者私有历史、工作目录或机器路径。新构建产生自己的记录，分发新字节前重新扫描及核对许可证。
