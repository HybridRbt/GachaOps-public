# 三月七助手：公开契约与证据边界

已登记兼容范围为 v2026.9.30、v2026.10.16、v2026.11.8、v2026.11.24；版本/配置摘要变化仍阻断。子启动链需确切身份和完成协议，新版本自然日常验收仍单独保留。

v2026.11.24 为离线源码审阅结论，实机验收待做：每日实训的报告文案已变化（新旧的「实训未完成/活跃度」与旧版任务明细两种格式都解析，实训未完成计入失败详情）；「每日实训活跃度 N/M」进度行独立于本轮是否领奖都会解析，活跃度满分只结算实训自身的失败项，不再清除其它任务的失败记录。启动前按 YAML 1.2 语义读取该版本新增的平台配置键：键名带引号、统一顶层缩进、冒号前空格、行尾注释、CRLF 等写法都能读取，值区分空值/布尔/字符串/数字并跟随上游的真值与默认行为（空的后端沿用云游戏开关，空界面按 PC、空操作模式按前台、布尔 False 或空值不视为「启动时先等待」）；任何无法确定解析的配置写法（列表、嵌套块、块标量、锚点/别名、标签、跨行值）都会被拒绝并指明是哪个设置项，建议在助手中重新保存该设置后再检查。云端/ADB 控制、触屏界面、后台操作模式或「启动时先等待」仍会给出明确阻碍。GachaOps 未接入三月七原生的暂停/恢复/停止文件协议；停止与超时仍由受控 Job 清理保证。

此页是公开导出的接口摘要，不复制内部会话、宿主盘点或账号证据。版本和证据等级以[兼容矩阵](SUPPORT_MATRIX.md)及程序内原始检查为准，不改写其证据日期。

离线验证使用合成 fixture，入口为 tests/test_march7.py、tests/test_registration.py；完整命令 `python -m unittest discover -s tests -v`。离线测试和历史链路不代表当前版本的实机验收。

保留全局锁、共享 journal、Job 所有权及 borrowed_game；完成、排他或清理不确定停止全链。真实助手、游戏及账号操作必须有对应授权。新增适配器见[开发契约](ADDING_ADAPTER.md)。
