# 外部助手许可范围

本版仅登记用户自行安装的助手，不交付助手安装包或游戏素材。以下为已核对上游版本的许可类别摘要，不替代对应版本原文，也不自动覆盖升级后的所有文件和依赖。

| 助手 | 已核对根许可类别 |
|---|---|
| OK-WW、MaaEnd | AGPLv3 |
| 绝区零一条龙、BetterGI、三月七 | GPLv3 |
| MaaGF2Exilium | MIT |
| OK-NTE | 仓库 GPLv3；网站 AGPLv3 标注差异保留，未作已澄清授权结论 |

自有代码和桥接采用 AGPL-3.0-only。一条龙桥接会在原助手环境导入其代码，不能仅凭进程边界推定没有组合义务。GPLv3 第 13 节允许相应组合；第三方部分保留适用条款。

未来复制、修改或再分发助手时，须重新核查实际版本、组合方式、源码交付及告知义务。本项目不替外部助手作隐私、安全或免封承诺。见[使用声明](USAGE_NOTICE.md)及[第三方交付清单](../THIRD_PARTY_NOTICES.md)。
