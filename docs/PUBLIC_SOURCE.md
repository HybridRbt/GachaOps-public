# 公开源码范围

公开候选由 `scripts/stage_public_source.py` 的显式集合导出。新文档默认不公开；更改公开集合需要内容复核。内部交接、会话、附件原名、宿主盘点、账号证据和授权过程保留在私有资料库。仅通过模式扫描不代表内容适合公开。

产品说明、开发契约、使用声明、兼容矩阵、汇总验收状态和发布手册属于公开文档。必要的第三方许可原文、对应源码索引及精确二进制策略按原字节保留。可执行源码不改写；命中隐私规则就阻断。材料不能靠替换敏感文本来保持旧摘要。

导出到源目录之外的新目录，检查文件集合、相对链接、源码扫描和人工内容复核后，才建立新的无父 Git 根；随后检查所有拟公开 refs。保留原私有历史和此前候选。导出器本身不自动添加 remote、推送或公开。维护者已确定目标为 [HybridRbt/GachaOps-public](https://github.com/HybridRbt/GachaOps-public)，先创建私有仓库并关闭 Actions，再上传重新审阅的独立源码根；实际公开另行决定。克隆使用 main 分支，见[源码入口](../README.md#源码入口)。原私有仓库与历史保留，不作为现行安装、源码或反馈入口。

源码根与二进制源码归档是不同交付物。已有二进制仍以构建时提交和其对应源码归档为准；新工程源码根不冒充旧 EXE 的构建来源。任何新字节需要对应检查，历史批准不能自动扩展。

运行说明见[快速开始](QUICKSTART.md)，接口见[适配器开发](ADDING_ADAPTER.md)，验证范围见[验收矩阵](VALIDATION.md)，交付步骤见[发布手册](release/RELEASE_RUNBOOK.md)。

兼容矩阵需要的既有 docs 路径由 docs/public/ 中独立编写的接口摘要导出；完整内部原件不修改、不公开。映射在导出器中显式列出；不改写运行时代码或矩阵。

干净仓库中的上述摘要保留 gachaops-public-evidence-v1 标记，可在相同显式路径再次导出；私有工作树有 public/ 对应文件时始终优先该文件。标记不替代人工内容审阅。

入口文档后续变化不能自动刷新旧候选材料批准。仓库内 DISTRIBUTION_APPROVAL 只适用于其中绑定的既有 app 和材料摘要；从新源码准备二进制交付时，必须重新核对真实文档字节、源码材料及批准范围。
