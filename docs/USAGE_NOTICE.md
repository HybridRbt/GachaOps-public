## 项目关系与用途

GachaOps 是独立开发的 Windows 本地助手编排工具，供自动化技术学习、交流及个人重复任务管理。它与各游戏运营方、发行商及所接入助手的维护团队没有官方隶属、代理或背书关系。文中游戏、助手名称和商标仅用于识别兼容对象，相关权利归各自权利人。

当前版本接入用户自行安装的助手，负责登记、检查、启动、串行调度、结果读取和进程收尾；不附带助手安装包，不代为下载、安装或更新助手。各助手的任务能力、数据处理和使用要求以其官方文档及对应版本为准。GachaOps 不提供游戏内存注入或游戏文件修改功能；这一说明不构成对所有第三方助手、插件或后续版本行为的保证。

## 使用前了解风险

- 自动化、模拟操作或其他第三方工具可能触及游戏协议并导致账号处罚，包括封禁。开源、免费、视觉识别或未修改游戏文件均不代表获得游戏运营方许可，也不构成免封保证。请先阅读适用服务器的官方协议和规则。
- 使用者须自行了解并承担使用 GachaOps 导致的账号问题及相关风险和后果，包括账号限制、冻结、封禁、资源损失及其他账号异常。
- 点击“开始运行”会执行所选助手中已保存的任务。原生预设可能包含消耗体力、领取奖励、购买或其他账号与资源变更；开始前应在各助手中逐项确认。GachaOps 的登记和只读检查不会替用户审核这些任务的全部后果。
- 游戏更新、界面变化、识别错误、网络或桌面中断可能导致误操作、未完成、资源损失或数据异常。请先核对支持版本和原生设置；发现异常及时停止，保留证据，勿绕过兼容或清理隔离提示。
- GachaOps 不承诺特定收益、任务必然完成、账号安全或持续可用。完成状态未知时不会显示为成功；停止及进程清理也不等于撤销已发生的游戏操作。
