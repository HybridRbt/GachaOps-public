# 验收范围与发布条件

公开 v1 尚未发布。下表只描述证据覆盖范围，不携带内部会话、机器身份或账号资料。

| 层次 | 当前覆盖 | 不代表的能力 |
|---|---|---|
| 核心与 Qt | 七适配器有离线回归；Windows 无游戏进程 fixture 验证部分执行边界 | 不等于真实助手或游戏验收 |
| 历史六游戏串行 | 一次历史版本链路获得用户确认，含已知原生任务失败 | 不覆盖后续版本、全部任务或 BetterGI |
| 本地冻结包 | 首启、只读 worker、重启及完整文件/材料校验有结果 | 不等于所有干净 Windows 环境 |
| 独立 Windows 基础界面 | 解压、首启/重开、组合持久化/列表移除、非法路径拒绝、取消与当前缩放布局通过；EXE 摘要匹配 | 不等于整包远端摘要、真实执行、UAC、只读目录或多 DPI 矩阵 |
| 公开发布 | 源码内容清理、真实入口、分阶段发布流程及必要条款核定仍须闭合 | 本地批准不等于公开发布批准 |

远端 CI 与本地测试分别记录；未实跑的平台和解释器不记为通过。兼容性以[精确版本和契约矩阵](SUPPORT_MATRIX.md)为准。执行、完成或收尾不确定时停止全链，不以退出码或旧结果代替证据。
