# 验收范围与发布条件

v0.1.0 已作为首次公开预发布交付。完整 Windows 环境、稳定版与新版助手验收尚未完成。下表只描述证据覆盖范围，不携带内部会话、机器身份或账号资料。

| 层次 | 当前覆盖 | 不代表的能力 |
|---|---|---|
| 核心与 Qt | 七适配器有离线回归；Windows 无游戏进程 fixture 验证部分执行边界 | 不等于真实助手或游戏验收 |
| 历史六游戏串行 | 一次历史版本链路获得用户确认，含已知原生任务失败 | 不覆盖后续版本、全部任务或 BetterGI |
| 本地冻结包 | 首启、只读 worker、重启及完整文件/材料校验有结果 | 不等于所有干净 Windows 环境 |
| 独立 Windows 基础界面 | 解压、首启/重开、组合持久化/列表移除、非法路径拒绝、取消与当前缩放布局通过；EXE 摘要匹配 | 不等于整包远端摘要、真实执行、UAC、只读目录或多 DPI 矩阵 |
| 公开预发布 | 独立干净源码、确切候选与对应材料经审阅后，以已批准本地 ZIP 人工上传；Release 与四附件已核验 | 不等于稳定版全部验收；不证明云端 materials/stage/publish 已执行 |

远端 CI 与本地测试分别记录；未实跑的平台和解释器不记为通过。兼容性以[精确版本和契约矩阵](SUPPORT_MATRIX.md)为准。执行、完成或收尾不确定时停止全链，不以退出码或旧结果代替证据。

2026-11-04 后续维护源码已完成组合永久删除确认与失败处理、改名保留未保存编辑、登记中文按钮与错误重选、清空可选登记路径，以及精确 GF2 v2.8.3 / MXU v2.8.1 接入的离线工程。Windows 本地完整回归运行 346 项，通过，1 项平台跳过；Qt 实际执行。独立评审的关键问题已用失败回归复现并修复。公开源码导出的隐私与相对链接检查通过。运行时兼容矩阵保留 Git 原始字节，避免 Windows 换行转换破坏冻结包与源码交付的一致性。

这些结果不改变已发布 v0.1.0 ZIP 的内容或批准。MXU 实际安装只做只读准备与指纹核验，尚未启动助手或游戏；当前版本的游戏 Job 继承、结束清理、串行交接及新冻结包仍需分别验收。
